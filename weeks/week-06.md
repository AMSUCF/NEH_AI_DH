## The Tools This Week

You don't need to use all of these. Pick what's most relevant to your work:

- **[Google Gemini Nano Banana](https://gemini.google.com/)** — Google's image-generation and editing tool, available free on most Google accounts. Surprisingly strong at infographics and photoreal edits.
- **[OpenAI Images / Sora](https://openai.com/sora/)** — generation across image and short video. Bundled with ChatGPT Plus.
- **[Claude Design](https://claude.ai/)** — Claude's slide and document layout mode (reach via the Artifacts toggle / "Design" affordance in the message composer). Generates editable PowerPoint-style decks, posters, and infographics from prompts.
- **[Claude voice mode](https://claude.ai/)** (mobile and desktop) — voice in/out for Claude conversation. Useful as a comparative point.
- **A voice interface you build in an Artifact** — using the Web Speech API; Claude can scaffold this in a single Artifact prompt.

## Exercise Menu

- <span class="tag tag-light">Light</span> **Infographic with Gemini Nano Banana or OpenAI Images 2.0 (~30 min).** Take a concept from your teaching or research that's easier to *show* than to *say* — a timeline, a process diagram, a relational map, a comparison. Generate it twice in two different tools (Gemini Nano Banana + one of OpenAI Images 2.0 or Adobe Firefly). Compare. What did each tool reach for first? What did each get wrong about your discipline?
- <span class="tag tag-standard">Standard</span> **Make a slide deck with Claude Design (~90 min).** Take notes from a lecture, a paper abstract, or a workshop you've given. Prompt Claude: *"Build a slide deck for a 15-minute talk based on this content. Use the Design / slide-deck Artifact. Make it visually distinctive — not the default corporate template."* Iterate at least three rounds — color, layout, typography, visual hierarchy. Notice what's faster than building it by hand and what's worse.
- <span class="tag tag-deep">Deep</span> **Build your own voice interface in an Artifact (~3 hr).** Open a new Claude conversation. Prompt: *"Build a Claude Artifact that's a voice interface for asking questions about [a topic in your course / a primary source / an idea from your research]. Use the Web Speech API for input and output. Include a clear visual indication of when it's listening and when it's responding."* Iterate. Talk to it. Compare to Claude's built-in voice mode. *(This exercise is a bridge to W7 Code Web — you're already building a tool with prompting.)*
